# 최근 5년 상표법 개정 핵심과 AI 시연

이승민 변리사(특허법인 그루)의 세미나 발표 페이지입니다.

- `index.html`: 발표 페이지 (표지 → 제1장 권리 확보 → 제2장 권리 행사 → 제3장 AI 시연 → 부칙)
- `tools/`: 시연 도구 (위임장 번역문 생성기, 증거번호 생성기)
- `files/`: 시연용 별첨 파일 (고객 위임장은 회사명·주소·서명·직인을 가린 사본)

발표 중 단축키: `→`/`PageDown` 다음, `N` 발표자 노트, `F` 전체 화면.
검색엔진 노출을 막기 위해 `noindex`를 걸어 두었습니다.
